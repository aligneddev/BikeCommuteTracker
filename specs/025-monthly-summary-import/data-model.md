# Data Model: Monthly Summary Import

**Feature**: `025-monthly-summary-import` | **Date**: 2026-06-25

---

## Schema Changes (Migrations Required)

### 1. `Rides` table — add `ImportSource` column

**Migration**: `AddImportSourceToRides`

```sql
ALTER TABLE Rides ADD COLUMN ImportSource TEXT NULL;
```

| Column | Type | Nullable | Default | Notes |
|--------|------|----------|---------|-------|
| `ImportSource` | TEXT | YES | NULL | `NULL` = manual ride; `"monthly-import"` = generated by monthly summary import |

**C# entity change**:
```csharp
// RideEntity.cs — add property:
public string? ImportSource { get; set; }
```

**DbContext configuration** (in `BikeTrackingDbContext`):
```csharp
entity.Property(static x => x.ImportSource).HasMaxLength(64);
```

**Impact on existing rows**: None. All existing ride records default to `NULL`.

---

### 2. `ImportJobs` table — add `ImportType` column

**Migration**: `AddImportTypeToImportJobs`

```sql
ALTER TABLE ImportJobs ADD COLUMN ImportType TEXT NOT NULL DEFAULT 'csv';
```

| Column | Type | Nullable | Default | Notes |
|--------|------|----------|---------|-------|
| `ImportType` | TEXT | NO | `'csv'` | `"csv"` = existing CSV import; `"monthly-summary"` = new monthly import |

**C# entity change**:
```csharp
// ImportJobEntity.cs — add property:
public string ImportType { get; set; } = "csv";
```

**Impact on existing rows**: None. Default value backfills all existing jobs as `"csv"`.

## Transient: Import Session State (no persistence)

The following data structures exist only in memory during a preview/start request. They are **not** persisted to the database.

### `ParsedMonthlySummaryDocument`

```csharp

public sealed record ParsedMonthlySummaryRow(
    int RowNumber,

    string? RawMiles,
    string? RawDays
);
```

### `MonthlySummaryRow` (post-parse, pre-validation)

```csharp
public sealed record MonthlySummaryRow(
    int RowNumber,

    decimal? Miles,
    int? Days,
```

### Validation Errors (shared with C#)

The F# module returns `Error "..."` strings. The C# `MonthlySummaryValidationRules` translates these into `ImportValidationError` records (existing type from `ImportContracts.cs`).

---

## Validation Rules Summary

| Rule | Code | Condition |
|------|------|-----------|
| Unrecognised month name | `INVALID_MONTH` | Raw month string not in recognised name list |
| Non-positive miles | `INVALID_MILES` | Miles ≤ 0 or missing |
| Non-positive days | `INVALID_DAYS` | Days < 1 or missing |
| Days exceeds weekdays | `DAYS_EXCEED_WEEKDAYS` | Days > weekday count in (month, year) |
| Per-day miles exceeds 200 | `MILES_PER_DAY_EXCEEDS_LIMIT` | floor(miles/days * 100)/100 > 200 |
| Intra-file duplicate month | `DUPLICATE_MONTH` | Same month appears ≥ 2 times in input |

## State Transitions: Import Job

```
[created] → awaiting-confirmation
[awaiting-confirmation] → processing     (StartAsync called)
[awaiting-confirmation] → cancelled      (CancelAsync called)
[processing]           → completed       (all rows processed)
[processing]           → failed          (unhandled exception in processor)
[processing]           → cancelled       (CancelAsync called mid-flight)
```

Monthly import jobs follow the same state machine as CSV import jobs. No new states added.
